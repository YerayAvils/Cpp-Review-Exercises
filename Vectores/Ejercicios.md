# Lista de ejericicos 
Ejercicio: Lista de números
Crea un programa que:
1. Declare un vector<int>.
2. Pida al usuario 5 números y los agregue al vector con push_back().
3. Muestre todos los números guardados.
4. Muestre:
   - el primer elemento
   - el último elemento
   - cuántos elementos tiene el vector
5. Pida al usuario una posición y muestre el valor que está en esa posición.
6. Elimine el último elemento con pop_back().
7. Muestre nuevamente el vector.
8. Vacíe el vector con clear().
9. Compruebe con empty() si quedó vacío y muestre un mensaje.
