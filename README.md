# C++ Review Exercises

Repositorio personal de repaso y práctica de C++.

El objetivo de este repositorio es reforzar los fundamentos del lenguaje, practicar conceptos nuevos y desarrollar ejercicios acumulativos que mezclen temas anteriores con los recién aprendidos.

## Estructura

- `01_fundamentos/`  
  Operadores, estructuras de control, funciones, scope y conversiones.

- `02_stl_y_datos/`  
  `vector`, `array`, `map`, `unordered_map`, `set`, iteradores y strings.

- `03_poo/`  
  Clases, constructores, getters/setters, herencia y polimorfismo.

- `04_memoria_y_referencias/`  
  Referencias, punteros, stack/heap, memoria dinámica y smart pointers.

- `05_archivos_y_organizacion/`  
  Archivos, excepciones, headers y proyectos con múltiples archivos.

- `06_cpp_moderno/`  
  `auto`, lambdas, templates, algoritmos STL, enums, structs y otros temas modernos.

- `07_ejercicios_acumulativos/`  
  Ejercicios que combinan varios temas aprendidos anteriormente.

## Objetivo

Usar este repositorio como registro de progreso hasta alcanzar una base sólida de C++ y poder construir proyectos más completos sin depender de tutoriales paso a paso.

## Metodología

1. Aprender o repasar un tema.
2. Resolver un ejercicio específico.
3. Resolver un ejercicio acumulativo.
4. Consultar documentación cuando sea necesario.
5. Subir cada avance usando Git y GitHub.
